  <p>3. 乾燥植物 0.1 g を 50 mL に調製し、原子吸光で吸光度 0.5 を得た。  
     検量線：濃度 (mg/L) = 20 × 吸光度  
     この植物の乾燥重 1 kg あたりのカリウム量 (mg/kg D.W.) を求めよ。</p>
  <button onclick="toggleAnswer('a3')">答え・解説を表示</button>

    1 kg（1000 g）あたりに換算：  
    0.5 mg ÷ 0.1 g × 1000 g = 5,000 mg/kg D.W.
